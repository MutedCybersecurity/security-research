Muted Cybersecurity studies security boundaries in open source software and works with maintainers to validate findings and coordinate fixes. This repository is a public record of **published** work. It does not contain active private reports, exploit code, or unpublished technical details.

## How we work

1. Establish the affected trust boundary and verify the behavior in an isolated environment.
2. Report privately through the project's preferred security channel.
3. Share concise reproduction evidence and retest proposed changes when invited.
4. Follow the maintainer's disclosure timeline. Publish only after coordination.

Read the [research approach](docs/research-approach.md) for more detail. For a reusable report structure, see our [disclosure templates](https://github.com/MutedCybersecurity/disclosure-templates).

## Scope of this repository

This is a curated portfolio of public records, not a vulnerability database or a claim of exclusive discovery. Credit type and wording follow each upstream advisory. Corrections to public links or attribution are welcome through a pull request; send sensitive material privately by email.
