# Contributing

Corrections to a published advisory link, wording, or attribution are welcome as pull requests. Please cite the public upstream source for any factual change.

Do not open a public issue or pull request containing an undisclosed vulnerability, a private advisory, personal data, credentials, or reproduction material that has not been cleared for publication. Send those matters to [cybersec@mut3dcybersecurity.com](mailto:cybersec@mut3dcybersecurity.com).
