Muted Cybersecurity estudia límites de seguridad en software de código abierto y colabora con los mantenedores para validar los hallazgos y coordinar las correcciones. Este repositorio recoge únicamente **trabajo publicado**.

Las [notas sobre los avisos publicados](docs/public-records.es.md) ofrecen un resumen breve de cada caso.

## Cómo trabajamos

1. Definimos el límite de seguridad y verificamos el comportamiento en un entorno aislado.
2. Comunicamos los resultados en privado por el canal elegido por el proyecto.
3. Compartimos evidencia clara y revisamos las correcciones cuando el equipo responsable lo solicita.
4. Respetamos el calendario de divulgación y publicamos después de la coordinación.

Consulta el [método de investigación](docs/research-approach.es.md) y las [plantillas de divulgación](https://github.com/MutedCybersecurity/disclosure-templates/tree/main/templates/es).

## Contacto

Sitio web: [mut3dcybersecurity.com](https://mut3dcybersecurity.com/) · GitHub: [@MutedCybersecurity](https://github.com/MutedCybersecurity)

Este repositorio es un registro de fuentes públicas, no una afirmación de descubrimiento exclusivo. Las correcciones de enlaces o atribuciones públicas son bienvenidas mediante pull request; los asuntos sensibles deben enviarse por correo privado.
